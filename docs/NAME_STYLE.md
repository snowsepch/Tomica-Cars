## 書寫格式

- 單車：`角色（類型）`，例如「閃電麥坤（標準型）」「脫線（總統型）」
- 台灣通路若用「…版」可保留（例「韓大夫（警車救援版）」）並在 sources 附通路 URL
- 避免中國大陸譯名（如「麦昆」「板牙」等）
- 遊具／套組在 notes 標「遊具／套組」
