# Tomica Cars／非 Tomica Cars 分類

建檔：2026-10-25（Asia/Taipei）

## 分類規則

| 分類 | 放什麼 |
|------|--------|
| **Tomica Cars（汽車總動員）** | 底盤或盒面有 TOMICA／Takara；C、SP、マック 等カーズトミカ。**在 Disney Store 買的 Tomica 也算這類**（通路不是廠牌）。 |
| **非 Tomica・Cars** | 同樣是汽車總動員角色，但不是 Tomica：Mattel、大型塑膠、回力、其他比例。 |
| 其他（本包不動） | 玩具總動員、一般車輛等既有分類維持。 |

- 實照對出的 **Tomica Cars 獨特款：48**
- 實照對出的 **非 Tomica Cars 獨特款：6**
- 暫不確定：5
