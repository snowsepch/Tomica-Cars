# Tomica Cars 圖源鐵則（2026-10-25）

## 優先順序
1. **官方商品圖**（Takara Tomy／官方發售頁）→ 優先使用。
2. **找不到官方圖時** → 可用 **實拍** 當備援。
3. **沒有乾淨可用的實拍** → 顯示「暫無官方圖」，不要破圖、不要硬塞原相機檔。

## 隱私鐵則（上線＝公開）
凡要進 GitHub Pages／公開 repo 的實拍，一律先假設會被永久爬取。上傳前必須：

1. **剝除所有拍攝中繼資料**：EXIF／GPS／海拔／方位／時間戳／相機廠牌型號／序號／Artist／Owner／Software／XMP／縮圖。
2. **視覺檢查**：無人臉或可辨身影、無居家可識別全景（門牌、窗景、獨特家具）、無證件／郵件／螢幕個資、無真實車牌、裁掉通路價簽。
3. **建議背景**：白紙／灰卡／純色桌墊；避免反覆出現同一木紋地板成為「家裡指紋」。
4. **禁止**：直接上傳 iPhone／相機原圖（本批 `已收藏車款` 原檔 **全部含 GPS**）。

## 本機路徑

| 已去 EXIF 可上架候選 | box `/workspace/tomica-image-policy/sanitized_photos/`（69 張，已驗證 GPS=0） |

## 覆寫舊規則
此鐵則 **取代** 2026-10-24「公開站一律禁止實拍」的 official-only 禁令。官方仍優先；實拍僅在無官方圖且已 scrub 後可用。
