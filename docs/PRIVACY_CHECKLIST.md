# 實拍上架前檢查清單

每張要進公開站的實拍，勾完才能放：

- [ ] 已用 `scripts/strip_exif.sh`（或同等）重編碼，exiftool 查無 GPS／Make／Serial／DateTimeOriginal
- [ ] 無人臉、無可辨身影／反光剪影
- [ ] 無門牌、住址、郵件、證件、螢幕個資
- [ ] 無真實車牌（玩具印刷除外）
- [ ] 已裁掉 funbox 等通路價簽（或色塊遮蓋）
- [ ] 背景盡量純色；木紋地板入鏡可接受但勿全景居家
- [ ] 確認該車款確實 **找不到官方圖** 才用實拍
- [ ] 檔名勿含真實姓名／地址；建議 `C-xx_slug_loose.jpg` 這類編號
